# AthleteSync API

The Laravel backend for AthleteSync. Setup, the API reference and design notes are in the [main README](../README.md).

```powershell
php artisan serve      # http://127.0.0.1:8000
php artisan test       # feature tests (uses the athletesync_testing database)
php artisan db:seed --class=DemoSeeder   # demo account: demo@athletesync.test / demo-password
```
